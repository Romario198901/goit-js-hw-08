# goit-js-hw-08

Simple JavaScript project: image gallery demo for the GoIT homework assignment.

**Description:** A minimal frontend project demonstrating a small gallery implemented with vanilla JavaScript, CSS, and HTML.

**Prerequisites:**
- A modern web browser
- Optional: a simple static server for local development (see Usage)

**Quick Start:**
1. Open `index.html` in your browser, or serve the folder with a static server.

Recommended local server commands:

```
# Python 3
python -m http.server 8000

# Or using npm
npx http-server . -p 8000
```

Then open http://localhost:8000 in your browser.

**Project Structure**
- [index.html](index.html): Main HTML file
- [css/styles.css](css/styles.css): Project styles
- [js/gallery.js](js/gallery.js): JavaScript for the gallery
